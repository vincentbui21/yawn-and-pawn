# Yawn & Pawn

An Android alarm clock where every snooze costs real money, rising with each snooze. Waking up is always free: you stop the alarm by completing a check you chose (Math, Word Unscramble, Memory Sequence, QR/Barcode, House Hunt).

Package id: `com.yawnandpawn.app` · Android first, iOS later · Kotlin Multiplatform + Compose Multiplatform.
