# Epic 3 retrospective (short), 2026-10-08

**Scope:** 13 code stories (3.1–3.13) plus the device checklist (3.14), run from 2026-10-06 ~11:00 to 2026-10-08 ~09:50. PRs #31–#40: 3.1, 3.3, 3.2 and 3.4 one by one; then stacks 3.5–3.8 (#35) and 3.9 + 3.13 (#36); then 3.10 (#37), 3.11 (#38), 3.12 (#40), plus the test-deflake PR #39. Wall clock about 47 h, including two usage-limit stops (about 1 h on 10-06 evening, about 15 h on 10-07 for the weekly limit) and a PC that slept for about 8 h during one gate.

## What went well
- **Reviews kept finding real problems.** Two reviewers per story found about 190 fixes. Several were alarm-safety issues: a word list that could crash every start or leave a Word alarm unwinnable, a camera that was busy, blocked or black with no fallback shown, the fallback link lost when the screen is rebuilt (auto dark mode at sunrise), focus moves that cut off TalkBack's Memory replay, Re-register silently re-enabling a switched-off alarm.
- **One extra review on integration commits** (3.10 wiring into 3.5–3.9 and 3.13) caught two bugs the story reviews could not see.
- **Specs written ahead** (3.11, 3.12) let a lane start the moment its base merged.
- **Fixing the flaky tests at the root (#39)** ended four failed CI runs in a row: leaked Robolectric components and screen reads before the UI settled, plus memory for the emulator step.
- **The device check found 4 bugs in 30 minutes** that no host test caught (test alarm ignores checks, heads-up over the wake screen, 0 % volume, Math too hard at Medium).

## What hurt
- **CI time:** about 30 min per run, and flaky failures cost 4 runs on #37 before #39 landed.
- **Stacking on unmerged bases** still meant repeated rebases (3.10 → 3.11 → 3.12) and one schema number reshuffle per stack (v6, v7, v8).
- **Usage limits:** the weekly limit stopped everything for about 15 h.
- **Device testing on the Oppo:** screenshots can't capture the camera picture, `am crash` leaves a dialog whose "Close app" acts like a force-stop, and uiautomator dumps sometimes fail.
- **Owner questions piled up** as "default taken": stepper range, Word heading, numbered fallback Memory, 200% grace header.

## Actions for Epic 4
1. Keep two lanes, two reviewers per story, one PR per stack. Add one integration review whenever a story is rebased onto stories it wasn't built with.
2. Merge the flaky-test fixes first if CI fails twice for non-code reasons; never re-run more than twice.
3. Device checks: keep test alarms at the lowest volume with vibration off; use a plain process death (not "Close app") for kill tests; recheck 3.14's item 16 in v2.
4. Ask the owner the open "default taken" questions in one batch at the start of Epic 4.
5. Payments need real Play testing with licence testers. Plan the owner's device session for Epic 4 early, not at the end.
